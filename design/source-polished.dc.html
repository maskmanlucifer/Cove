UX review · what changed and why
Grey text was too faint
Small text never goes lighter than #6B6D73 now (4.8:1 on canvas). The very light grey is only used on large type and placeholders.
The dock had icons with no labels
Each tab now has a label, and the active one is bolder. The voice button sits on its own so it’s always one thumb-tap away.
You couldn’t tell sheet rows were tappable
Rows that open a picker end in a chevron. Switches are only for true on/off settings.
The time marker had no time
The Schedule ‘now’ line now shows the time, so you can see the gap before what’s next.
AI acted without telling you
Every voice result is a draft until you tap Save, and there’s always an Undo. Suggestions say why, and can be turned off for good.
Voice had no way out
You can type on every voice screen. If Still only hears part of what you said, it offers its best guesses and never fails silently.
Permissions felt like a toll gate
Each one is explained first, can be skipped, and shows what still works without it.
Too many things competed on Today
Today has one focal card, three to-dos and two quick numbers. One-thing mode strips it down further.
Streaks punish missed days
Habits show how often lately, as 7 dots. Nothing resets to zero.
Alarm could be stopped by an accidental tap
“Hold to stop” fills over about a second. Snooze stays a single tap.
Delete looked as safe as Done
Delete is now a red text button with no fill, and it always comes with Undo.
Nowhere to edit categories from To-dos
There’s now an “Edit categories” link under the list.
Some things could only be done by voice
Expenses, categories and budgets, events, alarms and habits can all be added and edited by hand too.
Type sizes drifted from 11 to 13px
Nothing is smaller than 14px except dock labels (12px). Titles tighten as they grow and balance across lines.
